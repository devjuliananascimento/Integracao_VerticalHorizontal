# 📚 Integração Vertical e Horizontal

Repositório destinado ao armazenamento de **anotações, atividades e materiais complementares** da disciplina de **Integração Vertical e Horizontal**.

---

## 🎯 Objetivo

Organizar e documentar os conteúdos estudados ao longo da disciplina, facilitando:

- 📖 Revisão para provas  
- 📝 Acompanhamento da evolução dos estudos  
- 📂 Centralização das atividades solicitadas pelo professor  
- 🚀 Consulta futura para projetos acadêmicos e profissionais  

---

## 📌 Conteúdos Abordados

Alguns dos temas estudados na disciplina:

- Conceitos de Integração Vertical  
- Conceitos de Integração Horizontal  
- Arquitetura de Sistemas  
- Integração entre camadas  
- Comunicação entre serviços  

> A lista será atualizada conforme os conteúdos forem ministrados.

---

## 🛠 Tecnologias Utilizadas

Dependendo das atividades propostas, podem ser utilizadas tecnologias como:

- Git e GitHub  
- APIs  
- Banco de Dados  
- Ferramentas de modelagem  
- Outras ferramentas solicitadas em aula
